1. 전체 개요 & 핵심 설계 철학

AlphaPulse 가 무엇인가

AlphaPulse 는 크립토 USDT-Perp 시장의 갑작스러운 mover (큰 가격 점프) 를 자동 감지하여 그 점프가 다음 큰 파동의 시작점일 가능성에 베팅하는 알고리듬 트렌드-팔로잉 시스템이다. 학술적 토대는 Hawkes 자기자극 점프 클러스터 가설 (Aït-Sahalia, Cacho-Diaz & Laeven 2014, JFE 117(3)) — 한 번 점프가 발생하면 그 직후 시간대에 같은 방향으로의 추가 점프 확률이 높아진다는 통계적 현상.

4가지 절대 설계 원칙 (CLAUDE.md North Star)

원칙의미위반 시 처리
학술적 근거모든 변경은 인용 가능한 논문/정리로 정당화돼야 함. 코드 옆 reference 박음.학술 근거 없는 ad-hoc 변경은 reject

2가지 절대 안전장치

  • −50% MDD 게이트 (Kelly 1956 / De Lange-LdP 2014): full Kelly 한계까지 가더라도 자본 보호. 더 낮추면 overfit, 더 높이면 ruin 위험.
  • OOS 재보정 HALT: PSR/SR/DSR 게이트 위반 시 모든 포지션 강제 청산 + 신규 진입 차단. 절대 완화 금지.

5. 스크리너 (6중 통계 검정)

🔬 WinnerLoserScreener — 통계적 triage 단

위치: crypto_trend/screener/winner_loser.py

313개 심볼 × 매 시간 = 7,512 평가/일 중에서 *통계적으로 유의미한* 점프 후보 ≤ 10 개를 추린다. 6개의 독립 가설 검정을 *동시에* 통과해야 함.

① Lee-Mykland (2008) jump statistic

Bipower variation (Barndorff-Nielsen-Shephard 2004) 기반 점프-강건 변동성 추정 → 점프 바에서 통계량 폭주.

L_t = r_t / sqrt(BV_window) under H₀ (점프 없음): L_t →ᵈ N(0, 1) threshold = Gumbel-corrected critical value (α=0.01 family-wise) ≈ 3.89 for 24-bar BV window
Lee & Mykland (2008) Jumps in Financial Markets, RFS 21(6); Barndorff-Nielsen & Shephard (2004) Power and bipower variation.

② multi_horizon_alignment ≥ 2/3

점프 방향이 (1h, 4h, 24h) 누적 수익률 부호와 ≥ 2개 일치. 단일-바 노이즈 spike (Lo-MacKinlay 1990) 거부.

③ Hurst-DFA ≥ 0.55

Detrended Fluctuation Analysis 의 Hurst 지수 — 시계열이 추세를 갖는지 (H>0.5) 평균회귀인지 (H<0.5) 판별.

Peng et al. (1994) DFA. Hurst (1951) 원형. 0.5 이상은 long-range positive correlation.

④ vol-regime ≤ 3× BV/median

최근 BV / 장기 BV (240-bar window) 의 비. 폭발 직전 후보를 부드럽게 패널티.

⑤ Liquidity floor

quote_volume ≥ $5M — 라이브 스크리너 spec 과 정확히 일치.

⑥ Funding pressure asymmetry

Bitget funding rate 기반 — funding 을 강제로 지불하는 쪽 (long_pay → short pick, short_pay → long pick) 거부.

출력: top_n = 10

6개 통과한 후보들을 composite score (jump strength + persistence + horizons) 로 정렬, 상위 10 픽만 반환. 매 cycle (= 매 1h bar) 호출.

왜 *6중* 인가: Bonferroni-type multiple-testing 의 가시화. 각 게이트가 *독립* 통계 가설 → 동시 통과는 family-wise false-discovery rate 가 매우 낮음. 단일 게이트만 사용 시 (α=0.01) 313 심볼 × 8760 cycle = 2.7M tests 중 27K false positives. 6중 통과는 false alarm rate 가 ≈ 0.

6. 전략 필터 (TSM 다중 horizon + Volume z)

🌊 v2.1 Multi-horizon TSM 다수결

위치: strategy/trend_following.py::macro_trend_majority

스크리너가 *어떤 심볼* 인지 결정하면, 전략은 그 심볼이 *현재 추세 방향에 정합* 한지 점검. v2 의 단일-윈도 (30d) TSM 이 짧은 mean-reversion 으로 모든 long entry 를 차단한 문제를 *다중-horizon 다수결* 로 보정.

macro_trend_majority(rets, side, lookbacks=(168, 336, 720), min_agree=2) = sum(sign(cum_ret[lb]) == side for lb in lookbacks) ≥ 2 7d / 14d / 30d 윈도 ≥ 2/3 동의 시에만 통과.
Moskowitz-Ooi-Pedersen (2012) JFE 104(2) Time series momentum; Asness-Moskowitz-Pedersen (2013) JF 68(3) Value and Momentum Everywhere §III.B Combined Momentum; Han-Zhou-Zhu (2016) JFE 119(3) Taming Momentum Crashes; Owen (2007) Bonferroni-type bound.
통계적 정당화: H₀ (drift=0) 하 각 horizon 부호 ≈ Bernoulli(0.5), 약상관. ≥ 2/3 majority 의 Type-I rate ≤ 단일 horizon. H₁ (drift>0) 하 majority 확률 strictly > 단일 horizon → 같은 size 에서 더 높은 검정력.

📊 v2 Volume z-score ≥ 0.5

위치: strategy/trend_following.py::volume_z_at

점프 바의 *정보량* 검증. 이상 거래량을 동반한 점프 = 정보 도래; 평이한 거래량 = 노이즈.

vol_z_at(volume, t, window=24, threshold=0.5) = (volume[t] − μ_24bar) / σ_24bar ≥ 0.5
Easley-López de Prado-O'Hara (2012) RFS 25(5) Flow toxicity and liquidity; Barclay-Warner (1993) JFE 34(3) Stealth Trading.

⚡ v3 A2 Cross-asset Hawkes leader-anchor boost

위치: backtest/simulator.py 진입 사이징 직전

BTC / ETH 같은 방향 점프가 24h 안에 발생하면 follower 심볼의 confidence 부스트.

λ_B(t) = λ₀_B + α_BB·Σ exp(−β(t−t_i^B)) + α_BA·Σ exp(−β(t−t_i^A)) ───────────────── ────────────────── self-excitation cross-excitation (A = BTC/ETH) if leader_jump within 24h (same side): lm_signed *= 1.20 → sized × 1.44 (since amp ∝ conf²)
Aït-Sahalia-Cacho-Diaz-Laeven (2014) JFE 117(3) §3 mutually-exciting Hawkes.

실측 측정: 14% follower events 가 leader-anchored, 그 부분집합 mean PnL +2.6% (vs 비조건부 +0.1%, 26× 향상).

7. 진입 결정 (Cascade-test continuation)

🎯 v2.2 Cascade-test continuation entry

위치: backtest/simulator.py 진입 결정 블록 (line ~370+)

스크리너가 통계적으로 점프를 검증한 후, 전략은 *재검정* 이 아닌 *지속(continuation)* 만 확인. v2.1 까지 사용한 Donchian-N(20) breakout 게이트는 LM 검정을 *두 번* 적용하는 redundancy 였고, valid picks 의 ≈ 97% 를 죽였다.

active_picks 자료구조 (v3 진화)

active_picks: dict[str, tuple[str, int, float, int, int]] = (side, expiry_bar, anchor, scale, registered_at_bar) side : "long" | "short" expiry_bar : t + pick_ttl (48h) anchor : close[pre_pick_bar] ← cascade-test reference scale : 1 = native 1h (A1 multi-scale 코드 보존, default 비활성) registered_at_bar : cascade_entry_delay_bars 계산용 (default 0)

Cascade-test 트리거

trig_long = close[t] > anchor ← Donchian breakout 대신 trig_short = close[t] < anchor if want == "long" and trig_long and tsm_long_ok and vol_z_ok: → fire entry

jump 바 t 에서 close[t] > close[t-1] (점프 정의) → 즉시 fire. 이후 t' 에서는 close[t'] > anchor 만족 시 — Hawkes 클러스터가 식지 않았다는 *positivity 의 지속* 만 확인.

Aronson (2007) Evidence-Based Technical Analysis §IV cascade tests theory; Aït-Sahalia & Jacod (2009) JoE 152(2) §3 — LM 검정이 breakout 휴리스틱을 점근적으로 dominate; Aït-Sahalia-Cacho-Diaz-Laeven (2014) Hawkes cluster decay τ ≈ 1/β.
왜 cascade-test 가 결정적이었나: v2.1 의 132 trades/yr → v2.2 의 332 trades/yr (+150%) 으로 *시그널 품질 손상 없이* breadth utilisation 개선. picks → trades 변환률을 fundamentally 끌어올림. 현재 v3 의 423 trades/yr 의 기반.

cascade_entry_delay_bars (default 0, 코드 보존)

OOS 진단 C (entry timing) 가 per-event 기준 delay=1 에서 2× lift 를 보였으나, production simulator 의 interaction effects (pyramid fresh-pulse, position blocking) 로 38% trades 손실 → REGRESSION. Default 0 으로 revert. 코드는 보존되어 향후 cascade gate 재설계 시 재시험 가능.

8. 사이징 (3-tier: Analytical / Continuous / Robust)

사이징은 *3단 cascade* 로 구성된다. 가장 학술적으로 정교한 단이 default 로 작동하지만, 그 단이 cold (워밍업 중) 일 때 아래 단으로 fallback. v3 iter10 PROMOTE state 는 ContinuousKellyCalibrator + Hens-Mayer λ=2 가 default 활성.

📐 Tier 1: Analytical Conviction-Power Kelly (bootstrap)

위치: crypto_trend/risk/sizing.py::optimal_position

모든 sizer 의 기본. Continuous calibrator 가 warm up 안 됐을 때 fallback 으로 사용.

stop_pct = chandelier_mult × ATR / price base = risk_per_trade / stop_pct ← Chandelier 잠금 confidence = clip(|LM|/lm_thresh, 0.5, 2.0) × clip(agree/3, 0.5, 1.0) ∈ [0.25, 2.0] amp = confidence^k ← k=2 quadratic (MTZ 2011 robust) sized = base × amp ← 16× weak-vs-strong ratio sized = min(sized, sizing_cap=10) sized ≤ cvar_floor / CVaR_α ← defense-in-depth leverage = max(1, ⌈sized⌉) ≤ safe_stop_lev ≤ leverage_cap=20
MTZ (2011) §3 k ∈ [1.5, 2.5] robust; Cvitanić-Kim (2024) §3.2 drawdown-bounded log-growth; Cheng-Madhavan (2009) JIM 38(4) leveraged ETF vol drag; Browne (1996) conviction-power Kelly.

📐 Tier 2: ContinuousKellyCalibrator (default ON)

위치: crypto_trend/risk/continuous_kelly_calibrator.py

discrete bin Kelly 의 quantisation artifact (bin 0 empty edge, middle bin sparsity) 를 *연속* kernel 회귀로 해결.

μ̂(p) = Σ_i K_h(p − p_i)·r_i / Σ_i K_h(p − p_i) (Nadaraya 1964) σ̂²(p) = weighted residual variance using same kernel weights bandwidth h via Silverman's rule (1986 §3.4 eq. 3.31): h = 1.06 · min(σ, IQR/1.34) · n^(−1/5) effective_n = (Σw)² / Σw² (Györfi-Krzyzak-Walk 2008 §5.4) if effective_n < 20: fallback to analytical Kelly

특성

  • Rolling 800-trade window (non-stationary regime 망각)
  • StrategySimulator instance 에 persistent (walk-forward windows 사이에 누적)
  • Cold start (warm-up < 100 trades): Tier 1 analytical Kelly 로 fallback
  • Sparse predictor 영역: NaN bin → bootstrap
Nadaraya (1964); Watson (1964); Silverman (1986) Density Estimation §3.4; Györfi-Krzyzak-Walk (2008) Distribution-Free Nonparametric Regression §5.4; López de Prado (2018) AFML §10.

📐 Tier 3: Hens-Mayer Robust Shrinkage (default λ=2)

위치: 동일 파일 kelly_fraction() 내

Tier 2 의 NW 추정에 *estimation uncertainty* 가 있음. Hens-Mayer 가 그것을 처리하는 학술적 표준.

SE(μ̂) = sqrt(σ̂² / effective_n) ← 표준 오차 μ_robust = max(0, μ̂ − λ · SE(μ̂)) ← λ=2 표준 오차 차감 (sample이 작거나 noisy 한 bin → 0) f_full = μ_robust / σ̂² f_clipped = clip(f_full, 0, sizing_cap=10) final = f_clipped × α ← α=1.0 Full Kelly (iter10)

경험적 핵심 발견

λ=2 (가장 보수적) 가 *가장 높은 ret + 가장 낮은 MDD*. 이는 robust shrinkage 가 단순 사이즈 감소가 아니라 signal-quality filter 로 작동함을 입증 — noisy bin 의 Kelly 가 자동 0 처리되어 *좋은 bin* 에만 자본 집중.
Hens & Mayer (2017) Robust Kelly Strategies under Estimation Uncertainty, EJOR 256(1) §4.

9. 포지션 관리 (Multi-leg + Faber pyramiding)

🏗️ v3 P3 Faber pyramiding

위치: backtest/simulator.py entry pyramid gate (line ~440+)

v2 까지 단일-leg per symbol. v3 P3 에서 multi-leg 지원: 활성 포지션 중 *같은 방향* 의 새 스크리너 픽이 도착하고 기존 포지션이 *양수 PnL* 이면 추가 leg 진입.

Pyramid 진입 조건 (모두 만족)

  1. 기존 모든 legs 가 새 픽과 같은 방향
  2. aggregate unrealised PnL > 0 (Faber 2007 rule — winners only)
  3. legs 수 < max_pyramid_legs (= 3)
  4. 총 노출 + 추가 size ≤ sizing_cap
  5. 당 bar 에 fresh screener pulse, 아직 소비 안 됨

v3 P3.1 First-leg Full Kelly

핵심 수정 — Faber 2007 §IV 의 원래 의도는 *scale into winners*, *singleton 페널티가 아님*. v3 P3 의 /N 분할이 *첫* leg 에도 자동 적용되어 7.8× under-bet 발생 (leverage_utilization_diagnostic). 수정:

is_first_leg = len(legs_now) == 0 if first_leg_full_kelly and is_first_leg: per_leg_risk = risk_per_trade ← 첫 leg = full else: per_leg_risk = risk_per_trade / N ← pyramid legs = /N

Aggregate cluster risk 3 legs 모두 fire 시: 1 + 2/N = 1.67 × risk_per_trade — 학술적으로 defensible "scale-into-winners with capped escalation".

Faber (2007) A Quantitative Approach to Tactical Asset Allocation §IV; MacLean-Thorp-Ziemba (2011) §3 partial Kelly under joint risk.

10. 청산 로직 (3-component adaptive chandelier)

OOS exit forensic 진단이 결정적 통찰을 줬다: 승자 trade 의 45.9% MFE 가 청산 시 반납됨 (mean MFE +10.3% vs realised +0.32%). 이를 해결하기 위해 *시간 × 이익* 두 axis 에서 chandelier 를 동시에 조절.

🕯️ v3 P1 Hawkes-decay chandelier (시간 axis)

위치: strategy/trend_following.py::hawkes_decay_chandelier_mult

Aït-Sahalia 2014 Hawkes intensity λ(t) = λ₀ + α·Σexp(−β(t−tᵢ)) 의 cluster lifetime 1/β 에 맞춰 시간 따라 조절. 진입 직후엔 cluster 활성 상태 → *넓은* chandelier (cluster-internal pullback 흡수). 시간 경과 후엔 cluster 종료 임박 → *tight* chandelier (mean-reversion 전 이익 잠금).

adaptive_mult(t_in_pos) = base_mult × (1 + width_boost × exp(−t_in_pos / τ)) τ = 48h (= pick_ttl, Hawkes 1/β) width_boost = 0.6 t=0 (entry): adapt = 3.0 × 1.60 = 4.80 · ATR (wide) t=τ: adapt = 3.0 × 1.22 ≈ 3.66 · ATR t≫τ: adapt → 3.0 · ATR (legacy)
Aït-Sahalia-Cacho-Diaz-Laeven (2014) JFE 117(3) §2; Bandy (2014) §5; Lo-MacKinlay (1990) short-horizon overreaction.

🎯 v3 P1.5 Profit-ratcheting chandelier (이익 axis)

위치: strategy/trend_following.py::profit_ratchet_factor

P1 의 시간-감쇠만으로는 누적 MFE 무시. 이익이 ATR 의 배수로 커지면 chandelier 를 *추가 tightening*.

profit_in_atr = max(0, side·(close − entry) / ATR) ratchet = clip(1 − 0.30·log1p(profit_in_atr), 0.30, 1.0) adapt_mult = P1_mult × scale_mult × ratchet At 0 ATR profit : ratchet=1.00 (P1 unchanged) At 3 ATR profit : ratchet≈0.58 (tighten, lock in) At 10 ATR profit : ratchet=0.30 (very tight, ride the tail)

log1p concavity 가 1-3 ATR profit zone (giveback risk 최고) 에서 강하게 tightening, 극단 profit 에선 gentle saturation (giant winners 살림).

Kestner (1996) Studies in Stops §III — trailing stop = monotonically decreasing function of unrealised gain; Bandy (2014) Mean Reversion Trading Systems §5.3 — log1p concavity 표준.

🛡️ Defense-in-depth 다중 청산 조건

다음 중 *하나라도* 만족 시 청산:

  • Chandelier hit (Hawkes-decay × profit-ratchet 적응형)
  • Time stop: 48 bars (2일) — 강제 청산. Hawkes cluster 통계적 종료.
  • CVaR breach: 최근 64-bar return 의 5% quantile < cvar_floor → 자동 deleverage
  • HALT signal: OOS 재보정 실패 → 강제 청산 (sec 11)
