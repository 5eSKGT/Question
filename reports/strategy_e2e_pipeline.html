🔬 Screener Stage 1 — Triage PROD

잠재 picks 의 *통계적 신뢰성* 을 우주 단위에서 검증하는 단계. 6중 필터를 통과해야 cycle 의 top_n=10 후보에 진입.

구성 게이트 (모두 동시 만족)

  1. Lee-Mykland Lt 점프 검정 (Lee-Mykland 2008 JoF 21(6)): bipower-variation 으로 점프-강건 변동성 추정 → 잠재 점프 바에서 Lt ≫ N(0,1). Gumbel-corrected α=0.01 임계값 ≈ 3.89 — universe-wide multiple-testing 보정으로 false-discovery rate 제어.
  2. multi_horizon_alignment ≥ 2/3: 점프 방향과 (1h, 4h, 24h) cumulative return 부호 ≥ 2 일치. 단일-바 노이즈 spike 거부.
  3. Hurst-DFA ≥ 0.55 (Peng et al. 1994): persistence (지속성) 지표. 무작위 행보가 아닌 추세 가능성 검증.
  4. Vol-regime score ≤ 3×: 최근 BV / 장기 BV 비. 폭발 직전 candidate gentle penalty.
  5. Liquidity floor: quote_volume ≥ \$5M (live mirror).
  6. Funding pressure asymmetry: funding 을 강제로 지불하는 쪽 거부 (long-pay → short, short-pay → long).

출력

6,800 raw events / yr (313심볼 × 1년) → 4,675 events 가 다음 단계의 strategy filter 까지 통과.

학술 근거: Lee-Mykland (2008); Barndorff-Nielsen-Shephard (2004) bipower variation; Peng et al. (1994) DFA.
시너지: 6개 게이트가 *독립* 통계적 가설을 검증 (multiple-testing Bonferroni-corrected). 통과 시 picks 는 *통계적으로 강함 + 추세적으로 일관 + 지속성 있음* 의 교집합 — false-positive 가 cycle-level 에서 매우 낮음.
개선 후보 (학술 정합): z_alpha 와 min_horizons_agree 의 조정은 *직접 시도해서 reject 됨* (v2.3 — overfit). top_n=10 의 확대도 학술 정당화 부족. 이 layer 는 현 시점 최적.

🌊 Strategy Filter A — Multi-Horizon TSM 다수결 v2.1 PROD

점프 *방향* 이 macro-trend 와 정합하는지 검증. 단일 윈도 (MOP 2012 30d) 가 한 윈도 내 mean-reversion 으로 long entry 를 모두 차단하는 문제를 *다중-horizon 다수결* 로 보정.

macro_trend_majority(rets, side, lookbacks=(168, 336, 720), min_agree=2) = sum(sign(cum_ret[lb]) == side for lb in lookbacks) ≥ 2

7d / 14d / 30d 세 윈도가 ≥ 2/3 동의 시에만 진입. H0 (drift=0) 하 각 horizon 의 부호는 근사 Bernoulli(0.5), 약상관 → ≥ 2/3 majority 의 Type-I rate ≤ 단일 horizon (Owen 2007 bound). H1 (drift > 0) 하 ≥ 2/3 동의 확률 > 어떤 단일 horizon — 같은 size 에서 더 높은 검정력.

학술 근거: Moskowitz-Ooi-Pedersen (2012) JFE 104(2); Asness-Moskowitz-Pedersen (2013) JF 68(3) §III.B Combined Momentum; Han-Zhou-Zhu (2016) JFE 119(3) "Taming Momentum Crashes"; Owen (2007) Bonferroni-type bound.
시너지: 스크리너의 multi_horizon_alignment 가 *intraday* 일치 (1h/4h/24h) 를 보고, 전략 단의 macro_trend_majority 가 *macro* 일치 (7d/14d/30d) 를 봄. 시간 척도가 분리돼 redundancy 가 아닌 *cascade* — Aronson 2007 §IV.
모니터링 포인트: ±20% perturbation (tsm_lookback 480 / 960) 모두 PASS 확인됨. lookback 튜닝은 overfit 위험이므로 *변경 금지*.

📊 Strategy Filter B — Volume z-score v2 PROD

점프 바의 *정보량* 검증. 이상 거래량이 동반된 점프는 *정보 도래* (informed flow); 평이한 거래량의 점프는 *노이즈*.

vol_z_at(volume, t, window=24, threshold=0.5) = (volume[t] - μ_24bar) / σ_24bar ≥ 0.5
학술 근거: Easley-López de Prado-O'Hara (2012) RFS 25(5) "Flow toxicity and liquidity"; Barclay-Warner (1993) JFE 34(3) "Stealth Trading".
시너지: TSM 이 *방향* 을 검증하면 volume 은 *원인* 을 검증. 두 dimension 이 직교적이며 동시 통과 시 picks 의 informativeness 가 곱셈으로 누적.

🎯 Entry Trigger — Cascade-test Continuation v2.2 PROD

스크리너가 통계적으로 검증한 점프에 대해, 전략은 *재검정*이 아닌 *지속(continuation)* 만 확인. v2.1 까지 사용한 Donchian-N(20) breakout 게이트는 LM 검정을 *두 번* 적용하는 redundancy 였고, valid 한 picks 의 ≈ 97% 를 죽이고 있었음.

active_picks[sym] = (side, expiry, anchor, scale) anchor = close[pre_pick_bar] trig_long = close[t] > anchor ← Donchian 대신 fired_long = (want=="long" and trig_long and tsm_majority and vol_z_ok)

jump 바 t 에서 close[t] > close[t-1] (점프 정의 자체) → 즉시 fire. 이후 t' 에서는 close[t'] > anchor 만족 시 fire — Hawkes 클러스터가 식지 않았다는 *positivity 의 지속* 만 확인.

학술 근거: Aronson (2007) Evidence-Based Technical Analysis §IV cascade tests theory; Aït-Sahalia & Jacod (2009) JoE 152(2) §3 — LM-type 검정이 breakout 휴리스틱을 점근적으로 dominate; Aït-Sahalia-Cacho-Diaz-Laeven (2014) JFE 117(3) Hawkes cluster decay τ ≈ 1/β.
시너지: 이 single 변경이 v2.1 의 132 trades/yr → 332 trades/yr (+150%) 으로 *시그널 품질 손상 없이* breadth utilisation 개선. picks → trades 변환률을 fundamentally 끌어올림.
모니터링 포인트: pick_ttl 24h → 48h 확장 (AS-CD-L 2014 cluster timescale 의 학술 추정). 추가 확장은 stale-pick 위험.

🕯️ Exit · Hawkes-Decay Adaptive Chandelier v3 P1 PROD

고정 3·ATR chandelier 는 Hawkes 클러스터의 phase 를 무시. 클러스터 활성 초기엔 *넓은* chandelier 로 cluster-internal pullback 흡수, 클러스터 종료 임박엔 *tight* chandelier 로 mean-reversion 전 이익 잠금.

adaptive_mult(t_in_pos) = base_mult × (1 + width_boost × exp(−t_in_pos / τ)) τ = 48h (= pick_ttl, Hawkes 1/β) width_boost = 0.6 t=0 (entry): adapt = 3.0 × 1.60 = 4.80 · ATR (wide) t=τ: adapt = 3.0 × 1.22 ≈ 3.66 · ATR t≫τ: adapt → 3.0 · ATR (legacy)
학술 근거: Aït-Sahalia-Cacho-Diaz-Laeven (2014) JFE 117(3) §2 Hawkes 자기자극 강도 λ(t)=λ₀+α·Σexp(−β(t-tᵢ)); Bandy (2014) Mean Reversion Trading Systems §5 vol-adapted Chandelier; Lo-MacKinlay (1990) short-horizon overreaction.
시너지: upper_bound_diagnostic 가 입증한 핵심 사실 (alpha 는 점프 검출이 아닌 *비대칭 청산* 에서 발생 — skew +4.6) 을 직접 활용. 클러스터 시간 구조를 청산에 반영해 right-tail 을 더 잡음.
모니터링 포인트: width_boost=0.6 / τ=48h 는 학술 근거 (AS-CD-L 2014 cluster decay timescale) 에서 직접 유래. 데이터 튜닝 아님.

🏗️ Position Mgmt · Faber Pyramiding within Cluster v3 P3 PROD

활성 포지션 중 *같은 방향* 의 새 스크리너 picks 가 도착하고 기존 포지션이 *양수 PnL* 이면 추가 leg 진입. Faber 의 trend-following 정통: "winners only scale in, never losers".

진입 조건 (모두 만족)

  1. 기존 모든 legs 가 새 픽과 같은 방향
  2. aggregate unrealised PnL > 0 (Faber rule)
  3. legs 수 < max_pyramid_legs (= 3)
  4. 총 노출 + 추가 size ≤ sizing_cap
  5. 당 bar 에 fresh screener pulse, 아직 소비 안 됨

각 leg 의 size = (risk_per_trade / max_pyramid_legs) × amp — *aggregate cluster risk 가 single-leg risk 와 동일* 하게 partial Kelly 정합.

학술 근거: Faber (2007) A Quantitative Approach to Tactical Asset Allocation §IV winner-only pyramiding; MacLean-Thorp-Ziemba (2011) Kelly Capital Growth Investment Criterion §3 partial Kelly under joint risk.
시너지: Hawkes cluster 가 active 한 동안 (~48h) 같은 방향 picks 가 클러스터의 연속 점프 — 누적 노출이 합리적. P1 의 wide-early chandelier 가 multi-leg 의 cluster-internal 변동성 흡수.
모니터링 포인트: max_pyramid_legs=3 은 Faber 의 classical 1/3-each pyramid 정합. 학술 정당화 없이 증가 금지.

⚡ Cross-Asset Hawkes Leader-Follower Boost v3 A2 PROD

BTC / ETH 같은 방향 점프가 leader_anchor_decay_bars (=24h) 안에 발생하면 follower 픽의 conviction 부스트. Aït-Sahalia 2014 의 mutually-exciting Hawkes 의 직접 구현.

λ_B(t) = λ₀_B + α_BB · Σ exp(−β(t−tᵢ_B)) + α_BA · Σ exp(−β(t−tᵢ_A)) ───────────────────────── ──────────────────────── ────────────────────────── constant self-excitation cross-excitation (A=BTC/ETH) if leader_jump_within_24h(side): lm_signed *= leader_anchor_boost (= 1.20) → sized × 1.44 (since amp ∝ conf²)

upper_bound_analysis 가 측정: 1h follower events 의 14% 가 leader-anchored, 그 부분집합의 mean PnL = +2.6% (vs 비조건부 +0.1%, **26× 향상**).

학술 근거: Aït-Sahalia-Cacho-Diaz-Laeven (2014) JFE 117(3) §3 mutually-exciting Hawkes — α_AB 가 cross-excitation 강도, 동 §4-5에서 글로벌 자산군 contagion 실증.
시너지: v3 의 단일 single change 로 v2.2 의 cascade-test entry 기반에 *방향-검증된* 추가 lift 만 결합. Heterogeneous Kelly ceiling 의 14% 가 leader-anchored 라는 데이터를 직접 활용.
모니터링 포인트: τ=24h 는 AS-CD-L 2014 의 crypto-like Hawkes decay 추정. boost=1.20 은 conservative — α_AB 직접 추정으로 0.06-0.15 시사. 더 큰 boost (1.5-2.0) 시도는 다음 학술 정합 후보.

📏 Sizing · Conviction-Power Kelly PROD

Chandelier-pinned fixed-fractional risk × conviction-power amp × CVaR-floor cap × sizing_cap × safe leverage. 신호 강도에 *비선형* 으로 사이즈 스케일.

stop_pct = chandelier_mult · ATR / price base = risk_per_trade / stop_pct ← Chandelier 잠금 confidence = clip(|LM|/lm_thresh, 0.5, 2.0) × clip(agree/3, 0.5, 1.0) ∈ [0.25, 2.0] amp = confidence^k (k=2 quadratic, MTZ 2011 robust range [1.5, 2.5]) sized = base · amp ← 16× weak-vs-strong ratio sized = min(sized, sizing_cap=5) sized ≤ cvar_floor / CVaR_α ← defense-in-depth leverage = max(1, ⌈sized⌉), ≤ safe_stop_lev, ≤ leverage_cap=10
학술 근거: MacLean-Thorp-Ziemba (2011) §3 (k∈[1.5, 2.5] robust); Cvitanić-Kim (2024) §3.2 drawdown-bounded log-growth; Cheng-Madhavan (2009) JIM 38(4) leveraged ETF vol drag; Browne (1996) conviction-power Kelly.
시너지: P1 의 adaptive chandelier 가 stop_pct 를 동적 조정 → base 가 자동으로 cluster phase 적응. amp 의 비선형성이 right-tail 을 의도적으로 over-weight. CVaR floor 가 fat-tail 환경에서 자동 de-leverage.
모니터링 포인트: k=2 의 OOS 적정성은 ±20% perturbation (k=1.5, k=2.5) 으로 검증됨 — 둘 다 PASS. 현재 sizer 는 학술 정합 안에서 최적.

🛡️ OOS Adaptive Recalibration + HALT PROD

매 cycle 마다 최근 OOS bars 에서 PSR / SR / DSR 계산. PSR < 0.55 면 indicator 파라미터를 3번까지 자동 재보정 — 모두 실패 시 HALT (모든 포지션 강제 청산 + 신규 진입 차단).

구성

  • PSR (Bailey-López de Prado 2012): Sharpe 의 통계적 유의성 — finite-sample skew/kurtosis 보정
  • DSR (Bailey-López de Prado 2014): 다중 비교 보정된 Sharpe — backtest overfitting 방어
  • warmup 5 cycles (live) / 3 windows (backtest): 초기 sample 부족 false-alarm 차단
  • MIN_SAMPLES = 50: 50 미만이면 게이트 평가 자체 skip
학술 근거: Bailey-López de Prado (2012, 2014) PSR/DSR; López de Prado (2018) AFML §11 backtest cheating.
시너지: 모든 layer 의 상위 안전장치. 시그널이 *regime change* 로 무력해지면 손실 누적 전 자동 deleverage / HALT.
절대 금지: PSR/MDD/HALT 게이트 자체의 완화 — 안전장치를 부수면서 수익률 추구는 사용자의 본질적 자본 보호 의도와 정면 충돌. CLAUDE.md §5 명시.

핵심 발견 1: IC 가 *음수* — Lee-Mykland 점프 시그널 자체는 48시간 forward return 과 음의 상관 (Lo-MacKinlay 1990 short-horizon overreaction). 그러나 mean PnL 는 *양수* → 수익의 원천은 *시그널 검출이 아니라 execution mechanics* (skew +4.6 의 두꺼운 right tail + 3-ATR 비대칭 chandelier + Conviction-Power Kelly 비선형 사이즈).

핵심 발견 2 (heterogeneous Kelly): 신호 강도 빈에 따라 *별도* μ_b/σ_b² 를 적용 시 — Markowitz 1952 / Cover-Thomas 1991 §16 conditional log-optimal — homogeneous Kelly 천장 588%/yr 의 *142×* = +83,779%/yr 가 이론적 ceiling. 이는 사용자의 단일 100,000%/yr 목표를 *수학적으로* 안에 포함하는 구간. 단 모든 fractional-Kelly 실험에서 -20% MDD 게이트 초과 — *현 risk budget 안에서는 추출 불가능*.
