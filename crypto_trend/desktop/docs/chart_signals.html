SIGNAL_STYLE — 일관성 invariant

crypto_trend/ui/charts.py 안의 SIGNAL_STYLE 딕셔너리가 유일한 마커 결정자입니다. (side, type) 한 쌍이 정해지면 모양·색·크기가 하나로 고정되고, 출처(A/B/C)는 마커에 영향을 주지 않습니다. 이 invariant 는 tests/test_charts.py 가 단위테스트로 잠가둡니다.

OOS 강조 — 외곽 링

C 그룹은 시각적으로 빠르게 인지되어야 하지만, 그렇다고 마커 자체를 다르게 그리면 invariant 가 깨집니다. 그래서 마커는 그대로 두고 마커 위에 파란색 원형 아웃라인(circle-open)을 한 겹 더 얹습니다. 외곽 링은 레전드에서 토글 가능하지만 hover 정보에 끼지 않습니다.

중복 제거

매 사이클마다 같은 캔들 구간이 다시 재시뮬레이션되므로 동일한 (symbol, ts, type, side, source) 신호가 여러 번 후보에 오를 수 있습니다. PortfolioState.add_signal 는 이 키 조합으로 자동 중복 제거를 수행하므로, 차트에는 같은 사건이 단 한 번만 그려집니다. (내부적으로 1·2·3 분 안에 들어온 동일 키는 같은 신호로 취급)

차트 위 시간 정렬 보장

Plotly Scatter 의 markers 모드는 입력 순서가 그대로 그려지므로, 정렬을 위해 레전드 그룹별로 별도의 trace 가 생성됩니다. trace 추가 순서는 항상 HIST → LIVE → OOS 로 고정되어 있어 OOS 외곽 링이 가장 위에 얹히도록 z-order 가 결정적입니다.

이 문서는 라이브 실행 중 ⓘ 버튼으로 언제든 다시 열 수 있고, 차트 자체에는 최소한의 카운터/레전드만 남겨 가독성을 우선시했습니다.
